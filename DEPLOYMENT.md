# Public edition

Polymarket's [official widgets](https://help.polymarket.com/en/articles/13364174-how-to-use-embeds) show House/Senate control odds and four selected Senate/governor markets. Three lazy-loaded frames preserve provider attribution, disable buy buttons, and offer source links and manual refresh; they also reload every five minutes while the page is visible.

Every race card and the map's detail panel also show that race's Polymarket winner market: the top two outcomes with live prices and a link to the market. `public/market-map.json` maps race IDs to Polymarket event slugs. It is generated by `python3 scripts/build-market-map.py`, which reads open and resolved events tagged `midterms` and covered 506 of 507 races on election night (D.C.'s delegate has no market). `public/odds.js` reads each event's candidate list and settlement status from Polymarket's Gamma API and refreshes them every five minutes (matching that API's five-minute CDN cache), so a market that settles switches to its result within five minutes. It then fetches live midpoints for every on-screen race in one batched request to the order-book API (`clob.polymarket.com/midpoints`), once a minute while visible. Resolved markets show their outcome and are not polled. Prices are labeled as market prices, never affect colors, calls or alerts, and a failed read keeps the last price. Rerun the build script if Polymarket lists a new race market.

Decision Desk HQ's public forecast page is framed whole at its own URL with its branding, sign-in and update times intact. DDHQ's [terms](https://votes-docs.decisiondeskhq.com/terms-of-service) prohibit scraping and republishing its content; framing the live page displays it without copying, and no forecast numbers are read, stored or mixed into results, calls or odds. The frame reloads every five minutes while the tab is visible, and a manual refresh is offered. CSP adds only the `https://votes.decisiondeskhq.com` frame origin.

The crash-out watch reads four public Bluesky author feeds through [Bluesky's public App View API](https://docs.bsky.app) directly from the browser: PatriotTakes (quotes Trump's Truth Social posts), Catturd, MeidasTouch and the Trump Action Tracker. Truth Social itself sends `frame-ancestors 'none'` and rejects unauthenticated API reads, so it cannot be framed or fetched; mirrors of Trump's posts on Bluesky were checked and none has posted since August. Posts render as plain text with a link to the original; each feed is checked once a minute while visible, failures keep the last posts with a named warning, and no post text is stored anywhere.

All live results on the page come from one shared store, `public/ap.js`. Once a minute while the tab is visible it reads AP's Senate, House and governor results from [NPR's public results JSON](https://apps.npr.org/2026-election-results/) (three requests, revalidated rather than served from the browser cache; NPR's CDN caches for up to two minutes). The map, balance strip, call alerts and race desk all read that store, so they always agree. A failed read keeps each office's last good data.

The map shows AP for every race AP reports: vote shares from raw totals, percentage of expected vote counted, "Call by AP" and "AP via NPR" as the source, plus a link to the official results page watch.vote identifies. Races AP has not reported fall back to watch.vote's bulk results, with a note saying so. Where watch.vote's lead or call differs in party from AP's, the shape gets a dashed outline and the detail panel names what watch.vote shows. AP leads because watch.vote fell far behind on election night. At 9:35 p.m. Central it had no rows for 17 Senate, 18 governor and 220 House races AP reported (Mississippi and Michigan among them, despite fresh fetches) and had not marked 58 races AP had called. Where both covered a race, 26 vote shares differed by more than 3 points (CT-03: 50.2% vs AP 65.1%). It also showed Paxton leading in Texas while AP had Talarico ahead by eighteen points.

Wrangler deploys `public/` and compiles the single Pages function at `functions/api/map-results.js`. The public edition contains a race directory, a geographic election map, watch.vote's permitted embeds and the AP-backed surfaces above. It does not run the personal Python service, read its cache, or count flips. Displaying AP-sourced counts that NPR licenses was chosen to keep the page current on election night; removing `ap.js` and its consumers returns the page to watch.vote alone.

The balance-of-power strip counts AP race calls (a candidate's `winner: 'X'` marker) from the shared store. Senate totals add NPR's fixed holdover baseline (Democratic caucus 34 including two independents, Republicans 31). Governor bars count only tonight's 36 races. D.C.'s delegate is excluded from the House. Leads and forecasts never enter the bars. On election night the strip matched an independent tally of the same feeds exactly, including Louisiana's nonpartisan House rows.

The map's watch.vote fallback calls `/api/map-results?office=senate|house|governors`. This function reads watch.vote's documented bulk results API, checks its election and result fields, and caches successful responses for 60 seconds. It accepts only those three office values; it cannot proxy arbitrary URLs. No credentials or database are needed. `_routes.json` limits function execution to this endpoint, leaving static assets and private-path 404s outside it. The browser refreshes the active office about once per minute while visible. A failed refresh keeps the last results, and the warning appears only when AP isn't covering that office either. Upstream rate limits delay retries.

State and House district paths are bundled as static geometry, with no map tiles or browser map dependency. See [map sources](MAP_SOURCES.md) for the 2026 district snapshot, background state boundaries, build steps and licenses. The map distinguishes explicit calls, reported leads, tied votes, missing data and states without a race; named candidates without positive vote shares do not become leads. It displays source check times and flags checks over ten minutes old. AP's public page is linked rather than framed; its [terms](https://apnews.com/termsofservice) require permission for framing.

Home state and watchlist choices stay in the visitor's browser. A shared `?state=AR` link sets an initial home state. No address or browser location permission is needed. Each page loads at most six race cards. Above each card, a line shows AP's current leader, runner-up, expected vote counted or call from the shared store, updated in place each minute without reloading the watch.vote embed below it.

Call alerts check saved races and, by default, the 20 national featured races, all at once on every AP update (about once a minute). They never send their own requests. Checks pause while the page is hidden or alerts are paused; calls that arrive meanwhile alert on resume. Sound is opt-in. Calls and recent changes stay in each tab's session storage and survive reloads; separate tabs cannot overwrite each other's history. No notification subscription or server-side cache is created.

Only AP's explicit winner marker counts as a call. A race's first observation, including one with no votes yet, establishes a silent baseline; a call already made at that point is listed without an alert. Later calls produce alerts. A changed or withdrawn winner produces a correction. A failed feed read keeps known calls and lists the affected races as unavailable, and a race missing from a successful read keeps its last state. Detection time is local, not AP's call time.

## Preview and check

```sh
python3 -m unittest test_feeds.py test_public.py
node --test test_call_alerts.cjs test_markets.cjs test_forecast.cjs test_crashout.cjs test_balance.cjs test_odds.cjs
node --test test_map_api.cjs test_map_ui.cjs test_map_client.cjs
node test_public_ui.cjs
node --check public/app.js
npx wrangler@4.157.0 pages dev public --port 8788
```

Open `http://localhost:8788`. Check national links, home state, filters, paging and saved races. Counts come from third-party frames; a blocked frame always has an external race link.

## Publish to Cloudflare Pages

```sh
npx wrangler@4.157.0 login --scopes account:read user:read pages:write zone:read --use-keyring
npx wrangler@4.157.0 pages project create election-night --production-branch feat/election-night
npx wrangler@4.157.0 pages deploy public --project-name election-night --branch feat/election-night
```

Reuse the existing Pages project after its first creation. Use the production URL returned by Cloudflare; a local preview URL does not prove publication. Direct Upload does not create automatic GitHub deployments.

This project's production address is `https://election-night-959.pages.dev`. Wrangler 4.157.0 initially tried to create a Worker instead of the configured Pages project. Creation succeeded with `--force`, which selects Pages for that first creation; normal deployments to the existing project do not need that flag.

## Custom domain

Add `election.blaketownsend.com` under the Pages project's Custom domains. Then add the exact CNAME target Cloudflare supplies at the domain's DNS provider. For a subdomain, Cloudflare Pages does not require moving the whole domain's nameservers. Do not create the DNS record before associating the domain with Pages. Verify both DNS and HTTPS after activation.

The custom domain is registered with Pages. Its DNS record is `election CNAME election-night-959.pages.dev`, DNS only, in the `blaketownsend.com` Cloudflare zone. The domain owner moved the nameservers from Squarespace to Cloudflare during setup.

- The 507 directory entries comprise 435 House seats, 35 Senate races, 36 state governor races and the D.C. delegate. This is a directory, not a claim that every provider widget currently reports results. Territorial races other than D.C. are not included. Featured races are a browsing shortcut, not ratings or forecasts.
